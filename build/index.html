If a page renders as unstyled text

You have opened a file in _pages/. Those are body-only fragments with no <head>, no stylesheets and no header or footer, build.py assembles them into site/. Underscore-prefixed directories are source, never output.

Rebuilding

python build.py for development, or python build.py --prod to concatenate and minify the stylesheets into one request. Both write to site/, which is deleted and recreated each run, never edit anything in there by hand.
